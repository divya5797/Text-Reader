This is a simple *Text-to-Speech* web application built using *HTML, CSS, and JavaScript*.  
It allows users to type or paste text into a box, and then the browser will read the text aloud using the *Web Speech API*.  


Features
-  Write or paste any text  
-  Click *Read Text* to hear it spoken aloud  
-  Works directly in the browser (no backend required)  
-  Uses the built-in *speechSynthesis* feature of modern browsers  

Technologies Used
- *HTML5* – structure of the app

- *CSS3* – simple styling
  
- *JavaScript (Web Speech API)* – for converting text to speech
